# abdelhamidn.github.io

Interactive terminal portfolio, plain HTML/CSS/JS with no build step.
Live at https://abdelhamidn.github.io

Commands: `help`, `about`, `experience`, `skills`, `projects`, `contributions`, `education`, `links`, `contact`, `matrix`.
Contributions and repos are fetched live in the browser from public APIs.

Local preview: open `index.html`, or run `python -m http.server`.
